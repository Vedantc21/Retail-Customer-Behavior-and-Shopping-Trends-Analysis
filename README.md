# 🛍️ Retail Customer Behavior & Shopping Trends Analysis

## 📌 Project Overview

This project is a **real-world Data Analyst portfolio project** that analyzes retail customer behavior and shopping trends using a structured dataset.

It demonstrates an **end-to-end data workflow**:

* Data Cleaning & Transformation (Python)
* Data Storage & Querying (PostgreSQL)
* Business Insights & Visualization (Power BI)

The goal is to convert raw transactional data into **actionable business insights**.

---

## 🎯 Business Problem Statement

Retail businesses collect vast amounts of customer and transaction data, but struggle to:

* Identify high-value customers
* Understand purchasing behavior
* Optimize product performance
* Improve sales and retention strategies

👉 This project solves these challenges by analyzing customer transactions and generating insights that help in **data-driven decision-making**.

---

## ✅ Key Objectives

* Analyze customer purchasing patterns
* Identify top-performing product categories
* Segment customers based on spending behavior
* Discover sales trends over time
* Provide actionable business recommendations

---

## 🔍 Approach & Workflow

### 1️⃣ Data Cleaning & Transformation (Python)

* Handled missing values and inconsistencies
* Standardized data formats
* Prepared dataset for analysis using **pandas**

📁 File: `data_cleaning_analysis.ipynb`

---

### 2️⃣ Database & SQL Analysis (PostgreSQL)

* Created structured tables
* Simulated business queries
* Performed advanced SQL analysis:

  * Revenue calculation
  * Customer segmentation
  * Product performance

📁 File: `queries.sql`

---

### 3️⃣ Data Visualization (Power BI)

* Built an interactive dashboard to visualize:

  * Sales trends
  * Customer insights
  * Category performance

📁 File: `powerbi_dashboard.pbix` *(inside project folder/zip)*
